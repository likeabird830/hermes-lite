**踩坑经验：**
- Windows PowerShell 中 `git` 不在 PATH → 必须用完整路径 `C:\Program Files\Git\cmd\git.exe`
- Windows 控制台 GBK 编码不支持 emoji → log函数需要 UnicodeEncodeError 兜底处理
- 函数内 `import urllib.parse` 会导致 UnboundLocalError → 改为顶层 `from urllib.parse import urlencode`
- Register-ScheduledTask 需要 admin 权限才能用 SYSTEM principal → 改用当前用户 Interactive 登录
