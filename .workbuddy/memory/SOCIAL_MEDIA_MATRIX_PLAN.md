## 一、品牌核心定位（先搞清楚再动手）

### 你卖的不是"毛绒玩具"
你卖的是：**一个能对话、有性格、懂你的 AI 朋友 — 以毛绒为载体**

| 维度 | 定义 |
|------|------|
| **产品** | AI 毛绒伴侣（物理玩偶 + AI 人格，类似 Hermes 的"实体版"） |
| **目标用户** | 18-35岁，孤独感强、喜欢可爱事物、对AI好奇的人。攀岩者是种子用户但不是唯一用户 |
| **独特卖点** | "不是玩具，是朋友。它会记住你的名字、你的故事、你的攀岩路线。" |
| **品牌名建议** | 需要定一个。英文+中文。要有记忆点。（见下文分析） |
| **价格带** | $49-89（中高端，不是$15的超市货） |

### 品牌名头脑风暴（用1-3-1框架）

| 选项 | 名字 | 理由 | 风险 |
|------|------|------|------|
| A | **Pebble** (小石子) | 攀岩元素+可爱小巧+中性 | 可能被已有品牌占用 |
| B | **Chum** (伙伴) | 直接表达"朋友/AI伴侣"，简单好记 | 太普通可能难注册 |
| C | **Knot** (绳结) | 攀岩核心元素+象征"连接/纽带"| 发音可能不讨喜 |

> 🟢 **推荐选项A: Pebble** 或变体 **PebblePal / PebbleBuddy**
> 理由：攀岩者对小石头有情感连接（每次爬都摸），名字有画面感，适合做成角色IP。

## 三、各平台详细执行方案

### 🥇 TIKTOK — 主战场（流量引擎）

#### 为什么是P0
- **算法对新账号最友好** — 不需要已有粉丝基础
- **#climbing 标签日活巨大** — 攀岩内容在 TikTok 是蓝海中的蓝海
- **TikTok Shop Canada 已开放** — 可以直接挂车卖货
- **短视频制作成本最低** — 一部手机就能拍

#### 怎么建号

```
步骤1：下载 TikTok App → 用手机号注册
步骤2：用户名选 @pebblepal.xxx（或你定的品牌名）
步骤3：头像：你的AI毛绒玩具的高清照片（正脸，背景干净）
步骤4：Bio模板：
   🧸 AI plush that remembers you | 🧗‍♀️ Made for climbers & dreamers
   📍 Vancouver, BC 🇨🇦
   👇 Shop our first batch ↓
   [Link to等待建好的Shopify/Linktree]
步骤5：切换到 Pro Account（免费）→ 可以看数据分析
```

#### 起号策略（0→1000粉的路径）

**第一阶段（Day 1-7）：测试内容方向，找到爆款公式**

每天发 **2-3 条视频**，测试以下内容类型，看哪个数据好：

| 内容类型 | 模板 | 拍摄方式 | 预期效果 |
|----------|------|---------|---------|
| **A. 产品展示+反转** | "My mom thinks this is just a toy..." → 展示AI对话功能 | 手持玩偶自拍+画外音 | 😂 惊讶感→完播率高 |
| **B. 攀岩场景植入** | 带毛绒去抱石馆 → "My belay partner doesn't complain" | GoPro/手机架在垫子上 | 🧗 攀岩+可爱=反差萌 |
| **C. ASMR/治愈系** | 给毛绒整理毛发、穿衣服、放包里 | 近距离拍摄+轻音乐 | 😌 治愈→女性用户爱看 |
| **D. AI对话截图** | 截屏你和毛绒AI的有趣对话 | 录屏+配音 | 🤖 科技好奇→差异化 |
| **E. 打包/发货过程** | "Someone in Ontario ordered Pebble today!" | 仓库/打包台实拍 | 🔥 真实感→信任度 |
| **F. 用户故事** | "Customer from The Nest said..." | 征得同意后转发 | 💬 社交证明→转化 |

**起号铁律：**
- 前10个粉丝不重要。前100条视频都是数据。
- **每条视频必须有前3秒钩子** — 视觉冲击或听觉悬念
- 发布时间：**太平洋时间 11AM-1PM / 6PM-9PM**（通勤+睡前）
- 带 hashtag：#climbing #bouldering #ai #plushie #vancouver #cute #fyp #climbinglife

**第二阶段（Week 2-4）：加力数据好的方向**

- 如果 A 类（产品展示+反转）数据最好 → 大量做这类
- 如果 B 类（攀岩场景）数据最好 → 多去 gym 拍，和 gym 朋友合作
- **开始上 TikTok Shop** — 选1-2个SKU上架
- 回复每一条评论！评论区运营 = 免费算法加权

**第三阶段（Month 2+）：规模化**

- 日更 1-2 条高质量（不再追量追质）
- 开始做 **Series（合集）** — "Pebble's Gym Diary" 等
- 合作达人（micro-influencer，1K-10K粉，免费置换产品即可）
- 引流到 Discord 私域社群

#### 内容制作工具链（你已经有的Skills）

```
视频创意 → AI Video Script (写分镜脚本)
         → Video Workflow / JianYing Editor (剪辑)
         → TikTok Viral Editor (节奏优化)
配乐/音效 → 内置TikTok音乐库（免版权）
封面/文字 → Canvas Design / Beautify UI
文案/标题 → Copywriting (AIDA框架)
数据分析 → Marketing Metrics Review (周报)
```

### 🥉 FACEBOOK — 快速出单渠道（现金为王）

#### 为什么是P1（不是P0）
- FB 有机触达已经很低（Meta逼你投广告）
- 但 **Marketplace 和 Groups 是免费的本地流量入口**
- 适合温哥华本地快速出单（自提免运费）

#### 怎么操作

**A. Facebook Marketplace（今天就能发）**
```
1. FB App → Marketplace → Sell → Item
2. 分类：Toys → Stuffed Animals
3. 标题模板："🧸 AI Plush Companion - [Name] - Interactive Smart Toy"
4. 价格：$59.99 CAD
5. 描述：用Copywriting Skill生成（AIDA结构）
6. 照片：5-8张（正面/侧面/细节/尺寸对比/包装）
7. Location: Burnaby, BC
8. Delivery: Local pickup only (节省运费，增加见面机会)
```

**B. 加入这些 FB Groups（免费曝光）：**

| Group Name | 成员数 | 发帖策略 |
|-----------|--------|---------|
| Vancouver Buy Sell Trade | ~50K+ | 每周1次，非spam式分享故事 |
| Vancouver Climbing Community | ~3K+ | 分享攀岩相关内容，软植入 |
| Vancouver Moms / Parents of Vancouver | ~20K+ | 定位妈妈群体（礼物场景） |
| Burnaby / New Westminster Community | ~10K+ | 本地人，自提方便 |

**Group 发帖规则（避免被封）：**
- 不要一上来就卖东西
- 先价值输出 3-5 条（攀岩技巧/温哥华活动/育儿经验）
- 第 6 条开始软性提及产品
- 每个群每周最多 1 条推广帖

### 每周内容计划（总时间：每周 5-8 小时）

| 时段 | 任务 | 时间 | 产出 |
|------|------|------|------|
| 周一晚 (1h) | 批量拍素材 | 1h | 10-15个短视频素材 |
| 周二晚 (1.5h) | 剪辑 + 字幕 | 1.5h | 5-7条成片 |
| 周三晚 (0.5h) | 写文案 + 排期 | 0.5h | 一周的文案+发布时间表 |
| 周四晚 (1h) | IG图片编辑 + Stories | 1h | 3-4张Feed图 + 7条Story |
| 周五晚 (0.5h) | 发布 + 互动 | 0.5h | 全平台发布 + 回评论 |
| 周末 (2-3h) | 灵感收集 + 下周规划 | 2-3h | 竞品分析 + 创意库更新 |

### "一次拍摄，多平台分发" 工作流

```
        ┌→ TikTok（竖版9:16，15-30s）
        ├→ Instagram Reel（同上，改标题/hashtag）
拍摄一次 ┤→ YouTube Shorts（同上，加end screen）
        ├→ IG Story（裁剪成竖版，加贴纸互动）
        └→ FB Group/Marketplace（横版16:9或方图1:1）
```

**核心原则：一份素材，5个平台用。不重复造轮子。**
